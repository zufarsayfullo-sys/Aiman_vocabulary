# Korean Prime V2 — local prototype
Upload index.html, app.js, words.json, codes.json to the root of the existing GitHub Pages repository. Keep Teacher_passwords.txt private (separate download). Use HTTPS. This is not a production-secure backend: password hashes, answers and progress are client-side; users can bypass them. Progress and locks are local, not cross-device. Telegram ID is unverified. Focus/visibility/Telegram events are best-effort and may miss overlays or trigger on system UI. Audio uses device Korean speech synthesis. No microphone exercise. Original vocabulary preserved. Lesson 1 images are included. For later lessons upload images/L02_W001.jpg etc., numbered in original lesson word order (not round order). The app checks image availability when a lesson is first opened; reload after uploading new images. Missing images use the original translation fallback. Authored contextual gaps are not included; the gap stage uses a generic translation sentence. No teacher dashboard. Test on actual Android/iOS Telegram before assigning.
