# Korean Prime — local prototype
Upload index.html, app.js and words.json to GitHub Pages. In BotFather configure a Mini App/menu button with the HTTPS URL. Test on Android and iOS. This version stores progress locally, keyed by unverified Telegram user ID; it is not secure authentication. No teacher dashboard or Supabase backend is implemented. Lock is local and bypassable by clearing storage; screenshot blocking is unavailable. Speech recognition and audio depend on WebView support. Missing images fall back to Uzbek prompts; gap items use a generic vocabulary sentence unless a custom `gap` is supplied. Add image URLs and authored Korean gap sentences to each entry before production. Source extraction is automated and requires editorial review. No credentials included. Do not use for high-stakes assessment.
