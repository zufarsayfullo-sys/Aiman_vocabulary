# Korean Prime V2 — local prototype
Upload index.html, app.js, words.json, codes.json to the root of the existing GitHub Pages repository. Keep Teacher_passwords.txt private (separate download). Use HTTPS. This is not a production-secure backend: password hashes, answers and progress are client-side; users can bypass them. Progress and locks are local, not cross-device. Telegram ID is unverified. Focus/visibility/Telegram events are best-effort and may miss overlays or trigger on system UI. Audio uses device Korean speech synthesis. No microphone exercise. Original vocabulary preserved. Images and authored contextual gaps are NOT included in the source; add image and gap fields to each word. Until then the picture stage uses a translation prompt and the gap stage uses a generic translation sentence. No teacher dashboard. Test on actual Android/iOS Telegram before assigning.
